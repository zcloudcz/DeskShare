Hilfe in drei einfachen Schritten

  1. Laden Sie DeskShare herunter und öffnen Sie es auf Ihrem Computer.

  2. Wählen Sie „Ich brauche Hilfe“. Nennen Sie einer vertrauten Person Ihre Nummer und Ihren Code.

  3. Die helfende Person gibt beides im Browser oder in der App ein und sieht Ihren Bildschirm.

Der Code ändert sich alle 60 Sekunden. Lesen Sie dann den neuen Code vor.

Die helfende Person kann um die Steuerung von Maus und Tastatur bitten. Sie entscheiden bei jeder Verbindung; ohne Antwort wird die Anfrage nach 30 Sekunden abgelehnt. Sie können die Freigabe jederzeit beenden.

Unerwarteter Anruf? Nichts teilen.

Legen Sie auf und rufen Sie eine vertraute Person oder Firma unter einer geprüften Nummer an. Zeigen Sie kein Onlinebanking und geben Sie keine Passwörter weiter.

Schließen Sie vor dem Teilen private Fenster.

Technische Details

WebRTC überträgt den Bildschirm mit geringer Verzögerung und Ende-zu-Ende-verschlüsselten Medien (DTLS/SRTP), direkt oder über einen TURN-Relay. DeskShare ist kostenlos und quelloffen.
