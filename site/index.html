DeskShare
Jak to funguje Stažení GitHub EN

Sdílejte obrazovku Windows. Sledujte ji odkudkoli z prohlížeče.

DeskShare streamuje plochu přes WebRTC přímo mezi počítači, s latencí pod 150 ms. Přístup chrání passkey, který se mění každých 45 sekund.

Jak to funguje

  1. Nainstalujte DeskShare

    Na počítači, který chcete sdílet, spusťte aplikaci a klikněte na Start Server. Zobrazí se ID serveru a aktuální passkey.

  2. Pošlete ID a passkey

    Tomu, kdo se má připojit, stačí obojí přepsat do prohlížeče nebo do aplikace DeskShare. Passkey se každých 45 sekund obnoví.

  3. Rozhodněte o ovládání

    Ve výchozím stavu druhá strana obrazovku jen vidí. Myš a klávesnici povolíte vy, a kdykoli je zase odeberete.

Bezpečnost

Obraz jde přímo mezi počítači
WebRTC posílá video peer-to-peer, šifrované DTLS a SRTP. Server zprostředkuje jen navázání spojení, obraz přes něj neteče.
Passkey s krátkou platností
Každý pokus o připojení je podepsaný HMAC-SHA256 s aktuálním passkey a jednorázovým nonce, takže zachycený požadavek nejde přehrát.
Ovládání jen se souhlasem
Vzdálené ovládání myši a klávesnice je vypnuté, dokud ho na sdílejícím počítači nezapnete. Konkrétní klienty můžete trvale povolit nebo zablokovat.
Otevřený kód
Celý zdrojový kód včetně serveru je na GitHubu pod licencí MIT. Server si můžete provozovat i sami.
