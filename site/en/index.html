Share your Windows screen. Watch it from any browser, anywhere.

DeskShare streams the desktop over WebRTC directly between computers, with under 150 ms latency. Access is protected by a passkey that changes every 45 seconds.

How it works

  1. Install DeskShare

    On the computer you want to share, run the app and click Start Server. It shows a server ID and the current passkey.

  2. Send the ID and passkey

    The other person types both into the web viewer or the DeskShare app. The passkey renews every 45 seconds.

  3. Decide about control

    By default the other side can only watch. You enable mouse and keyboard control, and you can take it away at any time.

Security

Video goes directly between computers
WebRTC sends the stream peer-to-peer, encrypted with DTLS and SRTP. The server only brokers the connection; no video passes through it.
Short-lived passkey
Every connection attempt is signed with HMAC-SHA256 using the current passkey and a one-time nonce, so a captured request cannot be replayed.
Control only with consent
Remote mouse and keyboard control stays off until you turn it on at the sharing computer. Specific clients can be trusted permanently or blocked.
Open source
The full source code, server included, is on GitHub under the MIT license. You can also host the server yourself.
