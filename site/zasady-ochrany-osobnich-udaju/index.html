Zpracování osobních údajů

Účinné od 9. 10. 2026. Popisujeme, jaké osobní údaje zpracováváme při používání webu deskshare.zcloud.cz, aplikace DeskShare a webového prohlížeče obrazovky, v souladu s nařízením (EU) 2016/679 (GDPR) a zákonem č. 110/2019 Sb.

1. Správce

Martin Zahálka, Havlíčkova 1550/54, 680 01 Boskovice, IČO 07783809. Kontakt: martin@zcloud.cz. Pověřence pro ochranu osobních údajů jsme nejmenovali, protože k tomu nejsme povinni.

2. Jaké údaje zpracováváme

Web deskshare.zcloud.cz

  • Web je statický a hostuje ho GitHub Pages. GitHub při každém požadavku zpracovává IP adresu návštěvníka a technické údaje o prohlížeči.
  • Stránka si z GitHubu načítá číslo poslední verze aplikace. Při tom GitHub také vidí IP adresu.
  • Web nepoužívá cookies ani analytické a reklamní nástroje. Písma jsou uložená přímo na webu, takže se nic neposílá Googlu.

Připojení přes signaling server app.deskshare.zcloud.cz

  • Identifikátor sdíleného počítače (Server ID) a náhodný identifikátor diváka. Neobsahují jméno ani jiné údaje o uživateli.
  • IP adresa. Používáme ji k omezení počtu požadavků a k zaznamenání neúspěšných pokusů o přihlášení.
  • Údaje pro navázání spojení. IP adresy a porty, které si obě strany vymění, aby se mohly spojit napřímo. Server je jen přeposílá a neukládá.
  • Časy připojení a stav sdílení, například zda je počítač online.

Passkey ani heslo trvale neukládáme. Server ověřuje jen podepsanou žádost o připojení.

Obraz obrazovky a vzdálené ovládání

Obraz, pohyby myši a stisky kláves putují přímo mezi počítači a jsou šifrované (DTLS a SRTP). Server je nevidí. Pokud přímé spojení kvůli síti nejde, šifrovaná data přeposílá služba Cloudflare (TURN relay). Cloudflare obsah nevidí, zpracovává jen IP adresy a objem přenesených dat.

Aplikace v počítači

Aplikace si ukládá do vašeho počítače identifikátor, klíč instalace, uložená připojení a provozní logy. Tato data nikam neodesílá. Při spuštění kontroluje nové verze na GitHubu, který přitom vidí IP adresu.

3. Účel a právní základ

Údaje zpracováváme, abychom mohli navázat spojení mezi počítači a provozovat službu (plnění smlouvy, čl. 6 odst. 1 písm. b GDPR). IP adresy a záznamy o neúspěšných přihlášeních zpracováváme kvůli bezpečnosti a ochraně před zneužitím (oprávněný zájem, čl. 6 odst. 1 písm. f GDPR).

4. Doba uchování

  • Registrace počítačů, tokeny a údaje o připojení existují jen v paměti serveru. Mažou se nejpozději 15 minut po odpojení nebo při restartu serveru.
  • Provozní záznamy serveru (logy) uchováváme nejdéle 30 dní.

5. Zpracovatelé

  • Microsoft Ireland Operations Ltd.: provoz signaling serveru (Microsoft Azure, datacentrum West Europe, Nizozemsko).
  • Cloudflare, Inc.: přeposílání šifrovaného spojení (TURN), pokud přímé spojení nejde.
  • GitHub, Inc.: hosting webu a distribuce instalačních balíčků a aktualizací.

Údaje neprodáváme ani nepředáváme dalším stranám. Pokud u zpracovatele dojde k předání mimo EU/EHP, probíhá jen s odpovídajícími zárukami (EU-U.S. Data Privacy Framework, standardní smluvní doložky).

6. Vaše práva

Máte právo na přístup k údajům, jejich opravu, výmaz, omezení zpracování, přenositelnost a právo vznést námitku. Stačí napsat na martin@zcloud.cz. Máte také právo podat stížnost u Úřadu pro ochranu osobních údajů (uoou.gov.cz).
