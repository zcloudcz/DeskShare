De l’aide en trois étapes simples

  1. Téléchargez et ouvrez DeskShare sur votre ordinateur.

  2. Choisissez « J’ai besoin d’aide ». Communiquez votre numéro et votre code à une personne de confiance.

  3. Cette personne les saisit dans le navigateur ou l’application et voit votre écran.

Le code change toutes les 60 secondes. Lisez le nouveau s’il change.

Le contrôle est désactivé par défaut. Activez les demandes dans les options avancées avant le partage, puis approuvez chaque demande. Vous pouvez arrêter le partage à tout moment.

Appel inattendu ? Ne partagez rien.

Raccrochez et appelez une personne ou une entreprise de confiance à un numéro vérifié. Ne montrez pas vos comptes bancaires et ne communiquez pas vos mots de passe.

Fermez les fenêtres privées avant le partage.

Détails techniques

WebRTC transmet l’écran avec une faible latence et un chiffrement des médias de bout en bout (DTLS/SRTP), directement ou via un relais TURN. DeskShare est gratuit et son code est ouvert.
