🚀 Quick Start Guide

Step 1: Start the SignalingServer (already running if you used demo script)

cd src/SignalingServer
dotnet run

Step 2: Start the ScreenSenderApp (Windows only)

cd src/ScreenSenderApp
dotnet run

Step 3: Open WebClient in your browser

Open: src/WebClient/index.html

Step 4: Click "Connect" in the WebClient to start streaming!
